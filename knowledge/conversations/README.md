# Codex 会话来源

运行中显式导入的 Codex 会话会在这个目录生成 YAML 来源记录。

会话任务 ID、标题和摘要可能是个人信息，因此 `*.yaml` 默认被项目的 `.gitignore` 排除。

会话的默认沉淀产物是 `knowledge/documents/private/` 下的长文研究文档。完整结论、分层、边界、证据缺口和实施路线应留在文档正文中，图谱只展示文档、重点章节及其与技术/证据/实验的关系。

关键问题、回答、纠正和决策片段保存在 `anchors/`。每个锚点记录对应认知片段、会话来源、真实 `turn_id` / `item_id`、原文摘录、定位短句和内容哈希。当前 Codex 只能稳定打开任务级深链接，因此界面会先复制定位短句，再打开原任务供会话内搜索。

只有尚未能合理纳入文档结构的疑问、质疑、纠正和定位线索，才默认写入 `knowledge/nodes/private/`。私有文档、认知片段和锚点不会进入公开 Git 提交；对话仍然只是认知来源，不能自动升级为事实证据。

如果你在私有仓库中希望使用 Git 追踪这些来源，请先确认仓库权限，再根据自己的隐私策略调整 `.gitignore`。
